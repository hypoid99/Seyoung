# 🚚 세영건재 쇼핑몰 닷홈(Dothome) 배포를 위한 마이그레이션 가이드

본 가이드는 로컬 개발 환경(XAMPP)에서 최종 검증을 완료한 세영건재 온라인 쇼핑몰을 무료 호스팅 서비스인 **닷홈(Dothome)**으로 안전하고 간편하게 이전(마이그레이션)하기 위한 사전 준비 및 이행 절차를 정리합니다.

---

## ⚠️ 1. 마이그레이션 전 반드시 알아야 할 '직렬화(Serialization)' 이슈

워드프레스는 데이터베이스(DB)에 단순히 텍스트만 저장하는 것이 아니라, 설정 데이터나 위젯, 플러그인 설정 등을 **PHP 직렬화(Serialization)** 데이터 형태로 저장합니다.

* **예시**: `s:17:"localhost/seyoung"` (길이가 17인 문자열이라는 뜻)
* **주의사항**: 로컬의 DB를 백업받아 텍스트 에디터에서 단순 치환(`localhost/seyoung` ➡️ `username.dothome.co.kr`)을 할 경우, 글자 수 정보(17)가 실제 도메인 글자 수와 불일치하게 되면서 **DB 설정 정보가 통째로 깨져 사이트가 먹통(Error)이 되는 대형 사고**가 발생합니다.
* **대응책**: 도메인 치환 기능이 기본 탑재된 전문 마이그레이션 플러그인(**All-in-One WP Migration**)을 사용하거나, DB 가져오기 후 **Better Search Replace** 플러그인을 사용하여 데이터를 안전하게 변환해야 합니다. 본 가이드에서는 가장 안전하고 추천하는 **All-in-One WP Migration** 방식을 중점으로 설명합니다.

---

## 🏃 2. 단계별 마이그레이션 수행 절차

### 1단계: 닷홈 무료 호스팅 신청 및 워드프레스 설치
1. **닷홈 가입 및 신청**:
   * [닷홈 공식 홈페이지](https://www.dothome.co.kr)에 회원가입합니다.
   * `웹호스팅 > 무료 호스팅` 메뉴로 이동하여 무료 호스팅을 신청합니다.
   * **도메인 확인**: 신청 시 부여받는 기본 무료 도메인 주소(예: `http://username.dothome.co.kr`)를 메모해 둡니다.
   * **DB 및 FTP 정보**: 가입 시 설정한 FTP 아이디/비밀번호, MySQL DB 아이디/비밀번호를 반드시 기억해 둡니다.
2. **워드프레스 자동 설치 (CMS 자동설치)**:
   * 닷홈 마이페이지의 관리 화면에서 제공하는 **워드프레스 자동설치** 기능을 이용해 호스팅에 워드프레스를 기본 셋업합니다.

### 2단계: 로컬(XAMPP) 사이트 데이터 백업 (내보내기)
1. 로컬 워드프레스 관리자(`http://localhost/seyoung/wp-admin`)에 로그인합니다.
2. `플러그인 > 새로 추가`로 이동해 **All-in-One WP Migration**을 검색하고 설치 후 활성화합니다.
3. 알림판 왼쪽 메뉴에 신설된 `All-in-One WP Migration > 내보내기 (Export)`로 들어갑니다.
4. **'내보내기 대상'** 버튼을 클릭하고 **'파일 (File)'**을 선택합니다.
5. 로컬 사이트의 모든 DB, 미디어 파일, 테마, 플러그인이 하나의 압축 파일로 묶이기 시작합니다.
6. 완료되면 초록색의 `DOWNLOAD LOCALHOST` 버튼을 클릭하여 백업 파일(확장자 `.wpress`)을 내 컴퓨터 바탕화면 등에 다운로드합니다.

### 3단계: 닷홈(Dothome) 서버로 복구 (가져오기)
1. 신청한 닷홈 사이트의 관리자 화면(`http://username.dothome.co.kr/wp-admin`)에 로그인합니다.
2. 닷홈 사이트에도 동일하게 `플러그인 > 새로 추가`에서 **All-in-One WP Migration** 플러그인을 설치하고 활성화합니다.
3. 닷홈 관리자 좌측 메뉴에서 `All-in-One WP Migration > 가져오기 (Import)`로 들어갑니다.
4. **'가져오기 원본'** 버튼을 누르고 **'파일 (File)'**을 선택한 뒤, 2단계에서 로컬 컴퓨터에 다운로드해 둔 `.wpress` 백업 파일을 선택하여 업로드합니다.
5. 업로드가 완료되면 경고 창이 뜹니다. (기존 데이터베이스와 미디어 파일을 덮어쓴다는 내용) **Proceed (진행)** 버튼을 클릭합니다.
6. **고유주소(Permalinks) 저장**:
   * 복구가 완료된 후 반드시 `설정 > 고유주소 (Permalinks)` 메뉴로 두 번 이동하여 하단의 `변경사항 저장`을 두 번 눌러줍니다. (이 과정을 거쳐야 서버의 `.htaccess` 파일이 갱신되어 글 상세페이지나 숍 페이지의 링크 주소가 깨지지 않습니다.)

> [!NOTE]
> All-in-One WP Migration 플러그인은 복구(가져오기) 과정에서 DB 내부의 도메인 정보(`localhost/seyoung`)를 자동으로 감지하여 닷홈 도메인(`username.dothome.co.kr`)으로 **직렬화 규칙을 지켜 안전하게 일괄 변환(Replace)**해 줍니다.

## 🛠️ 3. 대안: FTP를 이용한 수동 마이그레이션 방법

만약 All-in-One WP Migration의 무료 버전 용량 제한(기본 512MB)에 걸리거나 호스팅 서버의 업로드 제한(Upload Max Filesize) 때문에 플러그인 이용이 어려울 경우, 아래 수동 방식으로 진행할 수 있습니다.

### 1. 파일 업로드 (FTP 사용)
1. **FileZilla** 등 FTP 접속 프로그램을 실행합니다.
2. 닷홈 호스팅 정보(호스트: `username.dothome.co.kr` 또는 `아이피 주소`, 사용자명, 비밀번호, 포트: `21`)를 입력하여 서버에 연결합니다.
3. 닷홈 서버의 워드프레스 루트 폴더(보통 `html` 또는 `/` 폴더) 내의 `wp-content` 경로로 이동합니다.
4. **자식 테마 업로드**:
   * 로컬의 `wp-content/themes/seyoung-theme/` 폴더 전체를 닷홈의 `wp-content/themes/` 경로로 업로드합니다.
5. **커스텀 플러그인 업로드**:
   * 로컬의 `wp-content/plugins/` 내에 있는 `seyoung-`으로 시작하는 커스텀 플러그인 6개 폴더 전체를 닷홈의 `wp-content/plugins/` 경로로 업로드합니다.

### 2. 데이터베이스(DB) 내보내기 & 가져오기
1. 로컬 phpMyAdmin(`localhost/phpmyadmin`)에 접속해 `seyoung_db` 데이터베이스를 선택하고 **'내보내기 (Export)'**를 진행하여 `.sql` 파일을 저장합니다.
2. 닷홈의 관리자 패널 또는 phpMyAdmin 주소로 접속하여 닷홈 MySQL DB에 로컬에서 받아둔 `.sql` 파일을 **'가져오기 (Import)'** 합니다.

### 3. DB 안전 도메인 치환 (Better Search Replace 플러그인 사용)
1. 닷홈 워드프레스 관리자에 접속한 뒤 **Better Search Replace** 플러그인을 설치 및 활성화합니다.
2. `도구 > Better Search Replace` 메뉴로 이동합니다.
3. **Search for**에 `localhost/seyoung`을 입력하고, **Replace with**에 실제 닷홈 도메인 주소(예: `username.dothome.co.kr`)를 입력합니다.
4. 모든 테이블을 선택하고 **'Run as dry run?' (실제 반영하지 않고 시뮬레이션만 하기)** 체크를 켜서 테스트 후, 이상이 없으면 체크를 해제하고 실행합니다.
5. 도메인이 직렬화 깨짐 없이 안전하게 정상 반영됩니다.
