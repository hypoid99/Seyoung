# 📋 세영건재 워드프레스 자식 테마 로컬 개발 핸드오프 가이드 (Handoff v20260615)

본 문서는 세영건재 워드프레스(자식 테마 `seyoung-theme`) 로컬 개발 세션을 종료하며, 다음 작업 담당자(또는 AI 개발 에이전트)가 이어서 작업을 매끄럽게 수행할 수 있도록 작성한 종합 핸드오프 파일입니다.

---

## 🚀 프로젝트 개요 및 환경
* **기반 테마**: Astra 자식 테마 (`seyoung-theme`)
* **로컬 구동 환경**: XAMPP (Apache, MySQL)
* **로컬 URL**: `http://localhost/seyoung`
* **고객센터 주소**: `http://localhost/seyoung/qna-board/`

---

## 🏆 주요 작업 완료 내역
지금까지 진행한 주요 작업 및 UI 고도화 내역은 다음과 같습니다:

1. **메인 캐러셀 및 서브 카테고리 퀵바 (로얄앤코 스타일)**
   * **풀와이드 서브바**: 카테고리 퀵 바 아래 마우스 호버 시 3~5개 서브 메뉴가 부드럽게 표출되는 가로 띠 형태 노출.
   * ** Swiper.js 연동**: 메인 히어로 3단 페이드 자동 롤링 캐러셀 적용. 모바일 슬림화 및 도트 겹침 현상 해결.
   * **반응형 드래그 스크롤**: 768px 미만 화면에서 모바일 가로 스크롤바 인지선 확보 및 PC 브라우저용 마우스 드래그-투-스크롤 스크립트 장착.
   * **약속 섹션 재배치**: "이달의 추천 베스트 상품" 아래로 위치를 이전하고 겹침 현상 조치.
   * **추천 상품 6개 확장**: 기존 4개에서 6개(3열 바둑판 배열)로 확장.

2. **GNB 최상단 로얄앤코 스타일 유틸리티 바**
   * 로그인 상태(LOGIN/JOIN ↔ LOGOUT) 동적 스위칭 및 비동기 AJAX 장바구니 숫자 배지 갱신 연동.

3. **고객센터(CS CENTER) 임시 페이지 및 전용 3단 푸터**
   * **템플릿 매핑**: [page-qna-board.php](file:///wp-content/themes/seyoung-theme/page-qna-board.php) 커스텀 템플릿 생성 및 슬러그 `qna-board` 페이지와 연동 완료.
   * **구조 모사**: 좌측 5대 사이드바(공지사항 등) + 우측 6대 아이콘(배송, 반품 등) + 자주 묻는 질문 TOP5 리스트 구현.
   * **정밀 SVG 아이콘**: 시안의 디자인을 본떠 상품문의(티셔츠), 마일리지(원형 M), 자주묻는질문(원형 FAQ)의 SVG 패스를 정밀화 및 모던 라인아트로 교체.
   * **레이아웃 결함 보정**: 아스트라의 공통 레이아웃 컨테이너인 `.ast-container`가 가로 flex 정렬을 취해 푸터가 본문 우측에 꼬여 붙는 버그를 발견, 해당 페이지 템플릿 한정으로 `.ast-container`에 `flex-direction: column !important;`를 강제 부여하여 하단으로 수직 안착 완료.
   * **포스트 타이틀 동기화**: DB의 페이지 포스트 제목을 '1:1 문의게시판'에서 '고객센터'로 수정 완료.
