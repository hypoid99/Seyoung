## 📐 3차 개발: 특화 기능 연동 (4대 플러그인)

모든 특화 기능은 우커머스 테마 호환성을 극대화하고 결합도를 낮추기 위해 **독립된 플러그인(Plugin)** 형태로 모듈화하여 개발되었습니다.

### 1. 타일 계산기 플러그인 (`seyoung-tile-calculator`)
* **플러그인 위치**: [seyoung-tile-calculator](file:///C:/xampp/htdocs/seyoung/wp-content/plugins/seyoung-tile-calculator/seyoung-tile-calculator.php)
* **주요 기능**:
  * 상품 등록/편집 화면의 일반 데이터 탭에 **'박스당 헤베(㎡) 면적'**(`_tile_area_per_box`) 메타 필드를 추가합니다.
  * 해당 필드 값이 입력되어 있는 상품 상세페이지에 한해, 수량 입력기 위에 **'타일 소요량 계산기'** 창을 자동으로 띄워줍니다.
  * 사용자가 **가로(m), 세로(m), 로스율(여유분 %)**을 입력하면 실시간으로 필요한 면적과 이를 채우기 위해 사야 하는 **올림 처리된 상자(Box) 수량**을 자동으로 계산합니다.
  * 계산된 상자 수량은 우커머스의 장바구니 수량(`qty` input)에 실시간 동기화되어 사용자가 바로 구매할 수 있게 돕습니다.

### 2. 1:1 Q&A 게시판 플러그인 (`seyoung-board`)
* **플러그인 위치**: [seyoung-board](file:///C:/xampp/htdocs/seyoung/wp-content/plugins/seyoung-board/seyoung-board.php)
* **주요 기능**:
  * 1:1 문의 전용 커스텀 포스트 타입(`seyoung_qna`)을 등록합니다.
  * 단축코드 `[seyoung_qna_board]`를 통해 게시판 목록 페이지 및 작성 양식을 제공합니다.
  * **비밀글 보호 기능**: 작성 시 '비밀글' 체크박스를 켜면 포스트 상태가 `private`으로 등록되어, 작성자 본인(로그인 유저)과 관리자(admin) 이외에는 목록에서 제목만 보이고 본문에는 🔒 접근이 제한됩니다.
  * **답변 상태 자동 전환**: 관리자가 해당 문의글에 워드프레스 기본 댓글(Comment)로 답변을 작성하면, 해당 포스트의 메타 필드(`qna_status`)가 자동으로 **'답변완료'**로 변경되며 목록 배지에 표시됩니다.

### 3. 시공 사례 갤러리 플러그인 (`seyoung-gallery`)
* **플러그인 위치**: [seyoung-gallery](file:///C:/xampp/htdocs/seyoung/wp-content/plugins/seyoung-gallery/seyoung-gallery.php)
* **주요 기능**:
  * 시공 포트폴리오 관리를 위한 커스텀 포스트 타입(`seyoung_gallery`)을 등록합니다.
  * 관리자 전용 메타박스를 지원하여 **'시공 전(Before) 이미지 URL'**을 입력받고, 사이트 내 판매 중인 **'우커머스 상품 태깅(체크박스 목록)'**을 제공합니다.
  * 단축코드 `[seyoung_gallery_list]`로 고객 화면에 카드형 갤러리 목록을 출력합니다.
  * 상세 페이지([single-seyoung_gallery.php](file:///C:/xampp/htdocs/seyoung/wp-content/themes/seyoung-theme/single-seyoung_gallery.php))에서 시공 전(Before)과 후(After) 사진을 비교해 보여줍니다.
  * 하단 영역에 태그된 실제 세영건재 상품 리스트(이미지, 가격, 바로가기 링크)를 쇼케이스 형태로 보여주어 시공 사례가 자연스럽게 구매로 연결되도록 유도합니다.

### 4. 등급별 우대가 플러그인 (`seyoung-grade-price`)
* **플러그인 위치**: [seyoung-grade-price](file:///C:/xampp/htdocs/seyoung/wp-content/plugins/seyoung-grade-price/seyoung-grade-price.php)
* **주요 기능**:
  * 플러그인 활성화 시 워드프레스에 **'시공기사'(`contractor`)** 회원 등급(Role)을 추가합니다.
  * 우커머스 상품 관리 화면의 가격 입력란 아래에 **'시공기사 우대가'**(`_contractor_price`) 필드를 추가합니다.
  * 로그인한 회원의 역할이 `contractor`인 경우, 우커머스 가격 관련 필터 훅(`woocommerce_product_get_price` 등)을 가로채 상품 리스트, 상세 화면, 장바구니, 결제 페이지 전체에 우대가 할인가를 즉시 적용합니다.
  * 시공기사 계정으로 상세 페이지에 접근 시 `🛡️ 시공기사 우대가 적용 상품` 배지가 출력됩니다.

  * **재고가 10개 이하인 경우**: 펄스 애니메이션이 가미된 주황색 **`🔥 품절 임박 (남은 수량: X개)`** 배지가 출력되어 고객의 구매 의사를 자극합니다.
  * **재고가 0개이거나 품절 처리된 경우**: 회색 톤의 **`❌ 일시 품절`** 배지가 선명하게 노출됩니다.

## 🧪 로컬 종합 검증 항목 및 방법

각 플러그인과 레이아웃이 로컬 XAMPP 환경에서 모두 정상 동작함을 확인했습니다. 추후 호스팅 서버 이전 후에도 다음 시나리오로 자가 진단을 할 수 있습니다.

### 1. 쇼핑몰 결제 흐름 검사
* **확인 사항**: 장바구니에 상품을 담고 주문서(Checkout)에서 결제가 끝까지 진행되는지 확인
* **방법**: 비로그인 또는 일반 회원 계정으로 접속하여 상품을 담고 결제 수단을 '무통장 입금'으로 지정한 뒤 주문 완료 페이지 및 관리자 주문 관리(`우커머스 > 주문`)에서 주문이 올바르게 들어왔는지 확인합니다.

### 2. 타일 계산기 연동 검사
* **확인 사항**: 가로/세로 값 입력 시 상자 수량이 잘 나오는지와 장바구니 자동 연동 여부
* **방법**: [바닥 타일 샘플 상품](http://localhost/seyoung/product/grey-floor-tile/) 등 박스당 면적이 기입된 상세페이지에 접속하여 가로 3m, 세로 3m, 로스율 10%를 입력해 봅니다. 필요 박스 수량이 정확히 계산되어 수량 칸에 입력되는지 보고, `장바구니 담기`를 눌러 장바구니 페이지에 해당 박스 수량이 그대로 실리는지 확인합니다.

### 3. 1:1 Q&A 및 답변 검사
* **확인 사항**: 비밀글 권한 보안 및 댓글 답변에 따른 완료 배지 처리
* **방법**: [1:1 문의게시판](http://localhost/seyoung/qna-board/) 페이지에서 일반 계정으로 '비밀글'을 체크하여 글을 작성합니다. 로그아웃 상태이거나 다른 일반 계정으로 로그인했을 때 상세 내용이 보이지 않는지 확인합니다. 이후 관리자(`admin`)로 로그인해 해당 글에 답글(댓글)을 달면 목록의 상태가 '답변대기'에서 '답변완료'로 자동 변경되는지 검증합니다.

### 4. 시공 사례 갤러리 검사
* **확인 사항**: Before/After 뷰 렌더링 및 하단 연관 상품 표시
* **방법**: 관리자에서 [시공 사례 갤러리](http://localhost/seyoung/wp-admin/edit.php?post_type=seyoung_gallery) 글을 새로 작성하고, 시공 전 이미지 URL과 사용 자재 체크박스를 선택하여 등록합니다. [갤러리 게시판](http://localhost/seyoung/gallery-board/) 목록에서 카드를 클릭해 상세 페이지로 들어가 Before/After 비교 영역과 하단 연동 상품 카드가 정상적으로 노출되는지 확인합니다.

### 5. 시공기사 우대가 적용 검사
* **확인 사항**: `contractor` 등급 계정 로그인 시 가격 할인 정상 작동 여부
* **방법**: 회원 관리에서 테스트 계정의 역할을 `시공기사`(`contractor`)로 지정합니다. 해당 계정으로 로그인한 상태로 쇼핑몰을 둘러볼 때 일반가 대신 우대가(할인가)로 가격 정보가 할인 적용되어 전 페이지에 표시되는지, 그리고 장바구니 및 주문 단계에서도 할인 가격으로 결제가 일어나는지 검증합니다.

### 6. 대량 견적 폼 및 재고 배지 검사
* **확인 사항**: 도면 파일 첨부 전송 시 DB 적재와 이메일 발송 여부, 재고 수량별 배지 색상
* **방법**:
  * [대량 견적 문의](http://localhost/seyoung/quote-board/)에서 도면 이미지나 PDF 파일을 첨부하여 견적 요청을 전송하고, 관리자 패널 `대량 견적 문의`에 전송된 글이 접수되었는지 확인합니다.
  * 임의의 상품의 재고 수량을 `5`로 줄였을 때 상품 카드 및 상세 페이지에 `🔥 품절 임박` 배지가 나타나는지, `0`으로 줄였을 때 `❌ 일시 품절` 배지가 표시되는지 확인합니다.
