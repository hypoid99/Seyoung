# 📐 세영건재 쇼핑몰 로컬 자가 검증 가이드

본 문서는 세영건재 온라인 쇼핑몰 개발 1~4차 결과물 및 신규 메인 홈 화면 리뉴얼 디자인에 대해 로컬 환경(XAMPP)에서 최종 작동성과 디자인 완성도를 검증하기 위한 가이드라인입니다.

---

## 🛠️ 1. 사전 준비 사항

자가 검증을 시작하기 전에 아래 서비스와 설정이 완료되어 있어야 합니다.

1. **XAMPP 실행**:
   * XAMPP Control Panel을 열고 **Apache**와 **MySQL**이 `Start` 상태(녹색 활성화)인지 확인합니다.
2. **로컬 쇼핑몰 접속**:
   * 브라우저를 열고 `http://localhost/seyoung` 주소로 접속합니다.
3. **관리자 로그인**:
   * `http://localhost/seyoung/wp-admin`으로 접속하여 관리자 계정(`admin`)으로 로그인합니다.
4. **검증용 테스트 계정 확보**:
   * 등급별 우대가 및 비밀글 Q&A 테스트를 위해 다음의 계정이 준비되어 있는지 관리자 메뉴 `사용자 > 모든 사용자`에서 확인합니다.
     * **시공기사 테스트 계정**: 역할(Role)이 `contractor` (시공기사)로 지정된 계정 (예: `contractor_test`)
     * **일반 회원 테스트 계정**: 역할이 `customer` (일반 고객)인 계정 (예: `customer_test`)

## 🧪 2. 기능별 상세 검증 시나리오 및 체크리스트

### 1. 🏠 메인 페이지 리뉴얼 디자인 검증
* **목적**: 밋밋했던 메인 화면이 고급스러운 베이지/브라운&골드 포인트의 레이아웃으로 변경되었는지 확인합니다.
* **검증 방법**:
  1. `http://localhost/seyoung` 홈 화면에 접속합니다.
  2. **히어로 영역**: 초고화질 프리미엄 욕실 배경 사진 위에 반투명한 유리 질감(Glassmorphism) 카드가 부드럽게 페이드인되며 나타나는지 확인합니다.
  3. **브랜드 약속 영역**: "Premium Quality", "Honest Price", "Expert Consulting"의 3개 카드와 아이콘이 깔끔하게 표시되는지 확인합니다.
  4. **카테고리 퀵링크**: 6대 제품군 카드가 노출되며, 마우스를 올렸을 때 카드가 살짝 떠오르고 화살표 아이콘이 오른쪽으로 밀려나는지 확인합니다.
  5. **추천 상품**: 우커머스 최신 상품 카드에 마우스를 대면 사진이 부드럽게 확대(Scale up)되고 `상세보기` 버튼이 페이드인 되는지 확인합니다.
  6. **모바일 반응형**: 브라우저 창 크기를 스마트폰 크기로 줄였을 때, 메뉴가 접히고 히어로 카드 텍스트가 깨짐 없이 알맞게 배치되는지 확인합니다.

### 2. 📐 타일 계산기 플러그인 검증
* **목적**: 헤베(㎡) 면적 입력 시 상자(Box) 수량 환산 및 장바구니 연동이 잘 되는지 확인합니다.
* **검증 방법**:
  1. 관리자 화면 `상품 > 모든 상품`에서 임의의 타일 상품(예: 바닥 타일) 편집 화면으로 들어갑니다.
  2. 일반 데이터 탭 하단에 `박스당 헤베(㎡) 면적` 필드(예: `1.44`)를 확인하고 숫자를 입력 후 저장합니다.
  3. 해당 상품의 상세 페이지로 접속합니다.
  4. 수량(`qty`) 입력기 영역 바로 위에 **'타일 소요량 계산기'** 상자가 렌더링되었는지 확인합니다.
  5. 가로 `3`m, 세로 `3`m, 로스율 `10`%를 입력합니다.
  6. **자동 환산 결과**: 필요한 면적은 `9.9`㎡이며, 필요한 상자는 올림 처리되어 `7`박스로 자동 계산되어 화면에 노출되는지 확인합니다.
  7. 계산 결과 `7`박스가 하단의 장바구니 수량 숫자 칸에 자동으로 입력(동기화)되는지 확인합니다.
  8. `장바구니 담기` 버튼을 눌러 장바구니 페이지로 이동한 뒤, 해당 상품의 수량이 정확히 `7`개로 담겨 있는지 검증합니다.

### 3. 🛡️ 시공기사 등급별 우대가 검증
* **목적**: 시공기사 회원 로그인 시 전 사이트에 할인가가 즉시 적용되는지 확인합니다.
* **검증 방법**:
  1. 관리자 화면 `상품` 메뉴에서 샘플 상품 하나를 선택하여 일반 가격(예: `30,000원`) 밑에 신설된 **'시공기사 우대가'**(예: `24,000원`) 필드에 금액을 입력하고 저장합니다.
  2. 로그아웃하거나 시공기사 계정(`contractor` 역할)으로 로그인합니다.
  3. 상점 아카이브(`/shop`) 및 해당 상품 상세 페이지로 이동합니다.
  4. 가격이 `30,000원`이 아니라 할인가인 `24,000원`으로 변경되어 표기되는지 확인합니다.
  5. 상세 페이지의 가격 바로 옆에 **`🛡️ 시공기사 우대가 적용 상품`** 배지가 선명하게 노출되는지 확인합니다.
  6. 상품을 장바구니에 담고 결제(`checkout`) 페이지까지 진행했을 때도 우대가 가격(`24,000원`) 기준으로 최종 결제 금액이 산정되는지 확인합니다.

### 4. 📝 1:1 Q&A 게시판 및 권한 검증
* **목적**: 비밀글 작성 시의 완벽한 권한 차단 및 관리자 댓글 답변 시 상태 자동 완료 처리를 확인합니다.
* **검증 방법**:
  1. 일반 회원 계정으로 로그인한 상태로 Q&A 게시판 페이지(`/qna-board`)에 접속합니다.
  2. 제목과 내용(예: "타일 견적 문의합니다")을 기입하고 **'비밀글로 작성'** 체크박스를 체크한 뒤 제출합니다.
  3. 등록 완료 후 목록 페이지로 돌아와 해당 문의글의 제목 옆에 🔒 아이콘과 함께 상태 배지가 **'답변대기'**로 뜨는지 확인합니다.
  4. 로그아웃하거나 다른 일반 회원 계정으로 로그인하여 동일한 `/qna-board`에 접속합니다.
  5. 비밀글의 경우 목록에서 본문 내용 미리보기가 차단되고, 클릭하여 상세 페이지로 접근하려 할 때 "비밀글입니다. 작성자와 관리자만 볼 수 있습니다." 등의 접근 경고 메시지가 뜨며 본문이 노출되지 않는지 검증합니다.
  6. 관리자(`admin`) 계정으로 다시 로그인하여 해당 Q&A 상세 글 페이지로 들어갑니다.
  7. 하단 댓글 창에 답변을 적고 등록합니다.
  8. 목록 페이지로 돌아왔을 때, 해당 문의 글의 상태 배지가 자동으로 **'답변완료'**로 변경되어 있는지 검증합니다.

### 5. 📸 시공 사례 갤러리 검증
* **목적**: Before/After 5:5 이미지 비교 뷰와 하단 사용 자재 상품의 연동 노출 상태를 점검합니다.
* **검증 방법**:
  1. 관리자 알림판에서 `시공 사례 갤러리 > 새로 추가`로 이동합니다.
  2. 시공 전(Before) 이미지 파일(혹은 URL)을 등록하고, 하단의 우커머스 상품 태깅 영역에서 해당 시공에 사용된 자재 상품들(예: 바닥 타일, 프리미엄 수전)을 체크한 뒤 글을 발행합니다.
  3. 고객 화면의 시공 갤러리 목록 `/gallery-board`에 작성한 카드가 잘 렌더링되는지 확인합니다.
  4. 카드를 클릭하여 상세 페이지로 접근합니다.
  5. 상세 화면 상단에 시공 전(Before)과 시공 후(After) 사진이 비교 가능한 뷰 구조로 예쁘게 정렬되어 있는지 확인합니다.
  6. 상세 화면 하단 영역에 태그한 우커머스 상품 리스트(상품 썸네일, 타이틀, 가격, 구매하러 가기 링크)가 격자형 쇼케이스로 정상 노출되는지 검증합니다.

### 6. ✉️ 대량 견적 요청 폼 및 재고 배지 검증
* **목적**: 도면/명세서 PDF 첨부 파일이 관리자 DB에 적재 및 이메일 발송되는지, 그리고 실시간 재고 기반 주황/회색 배지가 올바르게 활성화되는지 확인합니다.
* **검증 방법**:
  * **견적 폼**:
    1. 대량 견적 문의 페이지(`/quote-board`)로 이동합니다.
    2. 신청자명, 연락처, 상세 문의글을 적고 테스트용 PDF 파일(도면 명세서)을 첨부하여 제출합니다.
    3. 관리자 알림판 `대량 견적 문의` 메뉴로 이동하여 제출한 견적서가 DB에 정상 적재되었는지 확인합니다.
    4. 관리자 이메일 주소(또는 로컬 이메일 로그)로 첨부파일을 포함한 견적 접수 알림 이메일이 무사히 전송되었는지 검증합니다.
  * **재고 배지**:
    1. 관리자 화면에서 임의의 상품의 재고 수량을 `5`개로 설정하고 저장합니다.
    2. 해당 상품의 숍 페이지 카드 및 상세 페이지로 접속하여 주황색의 **`🔥 품절 임박 (남은 수량: 5개)`** 배지가 펄스 애니메이션과 함께 이쁘게 깜빡이는지 확인합니다.
    3. 해당 상품의 재고를 `0`개로 변경하거나 '품절' 처리합니다.
    4. 상품 카드 및 상세 페이지에 회색 톤의 **`❌ 일시 품절`** 배지가 선명하게 노출되는지 최종 검증합니다.
